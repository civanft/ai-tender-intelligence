# EU country flag assets

All 27 EU flags come from [flag-icons](https://github.com/lipis/flag-icons),
commit `086f7e97d657358203916dbe84f61c2bccaa81eb`, `flags/4x3/`.
Files retain their original SVG artwork and use ISO alpha-3 filenames matching
the project's country catalogue. See LICENSE for the upstream MIT terms.

The dashboard embeds these local assets as decorative CSS backgrounds at 8%
opacity. Visible country names supply the meaning; flags are not interactive
and do not require external image requests.
